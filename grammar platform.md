Cambridge Write & Improve (free, IELTS-friendly)

What it does: Instant CEFR feedback on paragraphs/essays.

How to use: Pick any Task 2 prompt → write 120–180 words → submit → note the highlighted grammar issues → rewrite the same paragraph focusing only on 1–2 error types (e.g., articles, SVA) → resubmit.

Muscle-memory trick: Create a “sentence bank” doc; for each error type, rewrite the target sentence 5 clean times with small variations.

2) Khan Academy – Grammar (free, structured drills)

What it does: Bite-size exercises with mastery tracking.

How to use: Do units on articles, subject–verb agreement, modifiers, punctuation. When you miss an item, copy the rule and immediately write 2 original sentences using the rule.

Muscle-memory trick: After each quiz, type a 3–4 sentence mini-paragraph using the target structure (e.g., “the/Ø/a internet…”).

3) British Council – LearnEnglish Grammar (web + app)

What it does: Level-based practice (B1–C1) with explanations.

How to use: Pick one grammar page (e.g., “Articles: a/an, the, no article”) → do the 3 practice tasks → then write 5 original sentences and check them with a checker (next item).

4) LanguageTool (free checker; great for sentence drilling)

What it does: Flags grammar/usage; lets you learn the rule.

How to use: Paste your 5–10 practice sentences → review the rule for each correction → retype the corrected sentence from scratch (don’t just click “accept”).

Muscle-memory trick: Keep a “Do/Don’t” list (e.g., “influence on, not to”), and retype those model sentences daily.

5) Perfect English Grammar (site with targeted drills)

What it does: Lots of focused worksheets (articles, prepositions, tenses).

How to use: Do a short exercise → take every wrong item and turn it into a cloze rewrite (“Wrong → Model”) → type the model sentence 3×.
